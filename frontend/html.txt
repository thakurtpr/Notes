-----------------------
1. Basic HTML Structure
-----------------------
HTML documents consist of a series of elements, represented by tags (<>). The basic structure of an HTML document includes:
<!DOCTYPE html>: Declaration of the document type
<html>: Root element of the document
<head>: Contains metadata about the document
<title>: Sets the title of the page
<body>: Contains the content of the page



Let's create a simple HTML document:
HTML
<!DOCTYPE html>
<html>
<head>
	<title>My First Web Page</title>
</head>
<body>
	<h1>Welcome to My First Web Page</h1>
</body>
</html>

3. HTML Attributes
-----------------------------

-----------------------------
4. HTML Semantic Elements
-----------------------------

Common Semantic Elements:
    header: Defines the header section of a document or section
    nav: Defines a set of navigation links
    main: Defines the main content section of a document
    section: Defines a self-contained section of related content
    article: Defines an independent piece of content, such as a blog post or news article
    aside: Defines content that is related to the main content, but not essential
    footer: Defines the footer section of a document or section
    Benefits of Semantic Elements:
    Improved search engine optimization (SEO)
    Better accessibility for screen readers and assistive technologies
    Enhanced readability and maintainability of code
    Easier styling and scripting with CSS and JavaScript
Examples:
    <header>...</header>
    <nav>...</nav>
    <main>...</main>
    <section>...</section>
    <article>...</article>
    <aside>...</aside>
    <footer>...</footer>


-----------------------------
5. HTML Lists
-----------------------------

Types of HTML Lists:
    Ordered Lists (<ol>)
    Unordered Lists (<ul>)
    Definition Lists (<dl>)

Ordered Lists:
    Use <ol> to define an ordered list
    Use <li> to define each list item
    List items are numbered automatically


Example:
    <ol>
        <li>Item 1</li>
        <li>Item 2</li>
        <li>Item 3</li>
    </ol>

Unordered Lists:
    Use <ul> to define an unordered list
    Use <li> to define each list item
    List items are bulleted automatically
Example:
    <ul>
        <li>Item 1</li>
        <li>Item 2</li>
        <li>Item 3</li>
    </ul>

Definition Lists:
    Use <dl> to define a definition list
    Use <dt> to define each term
    Use <dd> to define each definition
Example:
    <dl>
        <dt>Term 1</dt>
        <dd>Definition 1</dd>
        <dt>Term 2</dt>
        <dd>Definition 2</dd>
    </dl>

8. HTML Multimedia
-----------------------------   
HTML multimedia elements allow you to add audio, video, and images to your website.

Image Elements:
    <img>: Embeds an image
    src: Specifies the image URL
    alt: Specifies the alternative text
    width and height: Specify the image dimensions
Example:
    <img src="image.jpg" alt="An image" width="200" height="150">



Audio Elements:
    <audio>: Embeds an audio file
    src: Specifies the audio URL
    controls: Displays audio controls
Example:
    <audio src="audio.mp3" controls>
    Your browser does not support the audio element.
    </audio>



Video Elements:
    <video>: Embeds a video file
    src: Specifies the video URL
    controls: Displays video controls
    width and height: Specify the video dimensions
Example:
    <video src="video.mp4" controls width="400" height="300">
    Your browser does not support the video element.
    </video>




Other Multimedia Elements:
    <canvas>: Creates a canvas for dynamic graphics
    <svg>: Embeds an SVG image
    <embed>: Embeds a plugin or external content
    <object>: Embeds an object or external content

9. HTML APIs and JavaScript
-----------------------------   

HTML APIs:
    Document Object Model (DOM): Manipulates HTML elements
    Event Listeners: Responds to user interactions (e.g., clicks, hover)
    Storage: Stores data locally (e.g., localStorage, sessionStorage)
    Geolocation: Accesses device location
    Canvas: Creates dynamic graphics





JavaScript Basics:
    Variables: let, const, var
    Data Types: number, string, boolean, array, object
    Operators: +, -, *, /, =, ==, ===
    Control Structures: if, else, for, while, switch
    Functions: function, return


JavaScript Examples:
    Alert: alert("Hello, World!");
    Change Text: document.getElementById("id").innerHTML = "New Text";
    Show/Hide Element: document.getElementById("id").style.display = "none/block";

10. HTML Best Practices
-----------------------------   

HTML best practices ensure your code is readable, maintainable, and accessible.

1. Use a consistent indentation style
    Use spaces or tabs, but be consistent
2. Use meaningful element names
    Use descriptive names for IDs and classes
3. Use semantic HTML
    Use elements that describe the content (e.g., <header>, <nav>)
4. Close all tags
    Ensure all elements are properly closed
5. Use lowercase
    Use lowercase for element names and attributes
6. Use quotes around attribute values
    Use quotes around attribute values (e.g., href="url")
7. Use alt text for images
    Provide alternative text for images (e.g., alt="Image description")
8. Test for accessibility
    Ensure your website is accessible to all users
9. Use a validator
    Use an HTML validator to check for errors
10. Keep learning
    Stay up-to-date with the latest HTML developments
